# BRIEF CODEX — SITE DE DÉBARRAS STRASBOURG & ALSACE

## 1. Objectif du projet

Créer un site web moderne, très orienté conversion et SEO local pour une entreprise de débarras basée à Strasbourg et intervenant dans toute l’Alsace.

Le site ne doit pas être une simple vitrine. Il doit devenir un véritable outil commercial capable de :
- générer des demandes de devis qualifiées ;
- permettre l’envoi de photos ;
- rassurer rapidement le visiteur ;
- expliquer clairement les prestations ;
- valoriser le tri, le réemploi et le recyclage ;
- développer le référencement local sur Strasbourg, l’Eurométropole, le Bas-Rhin et l’Alsace ;
- préparer l’intégration future d’un simulateur de volume / estimation ;
- être performant sur mobile.

## 2. Positionnement recommandé

Promesse principale :

> Vous nous montrez ce qui doit partir. On s’occupe du reste.

Sous-promesse :

> Tri • Manutention • Évacuation • Valorisation • Nettoyage

Positionnement global :
- local ;
- humain ;
- professionnel ;
- rassurant ;
- simple ;
- rapide ;
- responsable ;
- orienté service clé en main.

Le site doit éviter un ton trop générique de “société de nettoyage”.
Il doit présenter l’entreprise comme une solution complète de débarras.

## 9. Simulateur de volume

À prévoir comme fonctionnalité importante.

Principe :
- sélection visuelle du volume ;
- éventuellement représentation camion ;
- 1/8 ;
- 1/4 ;
- 1/2 ;
- 3/4 ;
- camion complet.

Le simulateur peut servir à :
- améliorer la qualification des leads ;
- réduire le temps passé au téléphone ;
- préparer une estimation indicative.

Ne pas afficher un prix définitif si les données ne sont pas suffisantes.
