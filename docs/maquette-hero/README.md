Recette de H8 : Ams n'aimait pas la carte « Devis express » posée à cheval sur la photo, ni le vide
sous les trois garanties. Plusieurs versions ont été maquettées sur le vrai site ; **choix d'Ams :**

- **Ordinateur (≥ 900 px) — version C « photo en fond »** (`C-ordinateur-1280.jpg`, `C-grand-ecran-1440.jpg`) :
  la photo devient le décor assombri de tout le haut de page (dégradé vert foncé de gauche à droite),
  badge + titre + texte + boutons + garanties en clair à gauche, carte de devis blanche **entière** à
  droite, centrée verticalement. Rien n'est posé à cheval sur une photo.
- **Téléphone (< 900 px) — version D « titre sur la photo »** (`D-telephone-haut.jpg`, `D-telephone-devis.jpg`) :

  ensuite, sur fond clair : texte, boutons, garanties, puis la carte de devis. Le bouton « Obtenir mon
  devis gratuit » est visible dès l'ouverture.

`avant-ordinateur.jpg` : la version d'avant, pour comparer. Écartées : B (photo en bandeau à gauche,
